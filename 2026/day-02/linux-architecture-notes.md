Here’s a clear, rephrased version of your notes on Linux fundamentals, keeping all the points intact:

**Linux Fundamentals Overview**

Application and Shell: Applications interact with the shell, which then communicates with the kernel. The kernel manages communication with the hardware. The shell uses binary code to interact with hardware.

Tools for practice: Platforms like Utho, Killer Code, and AWS subscriptions can be used for hands-on learning.

Everything is a file: In Linux, everything is treated as a file or directory. Processes start by reading the file system.

**File System Basics**

Root directory: / is the root directory, and everything begins from it.

cd command: cd (change directory) lets you navigate folders. Example: cd /root/foldername.

ls command: ls lists files in a directory. Use ls -l for detailed information.

bin folder: Contains binary files. Avoid making changes here. The shell and kernel use binary language to provide output.

man command: Use man cp or man ps to get help on commands.

mkdir command: To create a folder, navigate to /home and run mkdir foldername. Then use cd foldername to enter it and ls to view contents.

**Essential Tasks**

Create folder: Use mkdir.

Copy/Move/Rename files: Use cp for copy, mv for move/rename. Example: cp source destination.

IP address: Run ip addr to view IP details.

Ping: Use ping website.com to test connectivity.

Storage check: Use free or df to view memory and disk usage.

Copy folder: Use cp -r folder1 folder2 for recursive copy.

Swap memory: Swap space is used when total memory is insufficient, acting as cache.

Processes: Use ps to view processes. ps -a shows active running processes.

Troubleshooting: ps aux | grep ping helps identify which process is running.

htop/top: Use htop or top to monitor active processes interactively.
