# My DevOps Learning Plan

## Who I Am
I am a student with no prior DevOps
experience but I am very curious about
cloud and automation and wanted to upskill
myself to reach MAANG level.

## My Understanding of DevOps
DevOps is a mindset. It is not about
knowing every tool. It is about knowing
which tool to use in which situation.
When I am working on something I should
be able to switch and adapt quickly
depending on what the problem demands.
That is what real DevOps looks like to me.

## Why I Started This
I came across TrainWithShubham community
and realized DevOps is what I want to do.
I am fully committed to what I say and
I will maintain discipline throughout
this entire 90 day challenge.
I want to build real systems and work at
a product based company someday.

## 3 Clear Goals
- Master Linux and Shell Scripting
- Build projects using Docker, Kubernetes and CI/CD
- Get AWS certified with a public GitHub portfolio

## 3 Core Skills
- Linux troubleshooting and automation
- Kubernetes and container orchestration
- CI/CD pipelines using GitHub Actions

## Daily Schedule
- Hour 1: Learn the concept
- Hour 2: Hands-on practice
- Hour 3: Document and push to GitHub

## Clear Plan
- Days 1 to 30: Linux, Shell Scripting,
  Git and GitHub basics
- Days 31 to 60: Docker, Kubernetes,
  AWS Core Services
- Days 61 to 90: CI/CD, DevSecOps,
  Terraform, Ansible and final project

Land a DevOps role at a MAANG or
