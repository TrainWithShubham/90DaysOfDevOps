## GitHub CLI (gh) Automation
* **`gh auth login`**: Authenticates your terminal with your GitHub account.
* **`gh repo create <name> --public`**: Creates a new repository directly from the terminal.
* **`gh issue create --title "..." --body "..."`**: Opens a new issue on the repository.
* **`gh pr create --title "..." --body "..."`**: Creates a new Pull Request from your current branch.
* **`gh pr merge --merge --delete-branch`**: Merges an open PR and automatically cleans up the old branch.
* **`gh pr list`**: Shows all currently open Pull Requests for the repository.
